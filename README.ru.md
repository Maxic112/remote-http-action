# Remote HTTP Action

[English](README.md) · **Русский**

Приложение для Windows, которое превращает компьютер в управляемый по HTTP узел.
В приложении настраиваются **flow** — последовательности действий: выключение, перезагрузка, сон, задержка, выполнение команды или скрипта, запуск программы.
Авторизованный запрос `POST /flow/<путь>/` с API-ключом запускает соответствующий flow.

## Возможности

- HTTP API с авторизацией по API-ключам, ключи хранятся в виде хеша.
- Группы доступа: какие flow доступны каким ключам.
- Синхронный и асинхронный режим ответа, таймауты, очередь, пауза между запусками.
- Задержка старта с обратным отсчётом на экране и возможностью отмены.
- Ограничение по IP-адресам и заголовку `Host`, поддержка reverse proxy, временная блокировка при переборе ключей.
- HTTPS с самоподписанным или собственным сертификатом.
- Журналы HTTP-запросов, команд CLI и выполнения flow с ротацией.
- Работа в фоне с иконкой в трее, автозапуск с правами администратора через планировщик заданий.
- Индикатор прав администратора и перезапуск с повышением.
- Полное управление через командную строку (`remote-http-action-cli.exe <команда>`), включаемое в настройках.
- Автоматическое обновление из релизов GitHub.
- Интерфейс на русском и английском.

## Быстрый пример

```bash
curl -X POST http://<адрес-компьютера>:8765/flow/sleep/ -H "Authorization: Bearer rha_XXXXXXXX..."
```
