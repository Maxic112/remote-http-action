# Журнал изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [Semantic Versioning](https://semver.org/lang/ru/).
Раздел версии публикуется как описание релиза на GitHub и показывается в программе на экране «Обновление».

## [1.0.0] - 2026-11-01

Первый выпуск.

### Возможности

- HTTP-сервер для запуска flow — заранее настроенных последовательностей действий — по запросу с API-ключом.
- API-ключи (хранятся только в виде хеша) и группы доступа к flow.
- Действия: выключение, перезагрузка, сон, задержка, команда (cmd, PowerShell, pwsh, WSL), скрипт, запуск приложения
  с ожиданием завершения процесса, дерева процессов или процессов по имени.
- Синхронный и асинхронный ответ, таймауты, очередь, пауза между запусками, задержка старта с отменой на компьютере.
- Ограничения по IP и заголовку Host, доверенные reverse proxy, временная блокировка при переборе ключей, HTTPS.
- Журналы HTTP-запросов, команд CLI и выполнения flow с ротацией и просмотром в программе.
- Работа в трее, автозапуск с правами администратора через планировщик заданий, индикатор и перезапуск с повышением прав.
- Полное управление через консольный `remote-http-action-cli.exe`.
- Автоматическое обновление из релизов GitHub для MSI и портативной версии.
- Интерфейс на русском и английском.
