# Ошибки и коды ответа

Ошибки возвращаются в едином формате:

```json
{ "error": { "code": "UNAUTHORIZED", "message": "invalid API key" } }
```

`code` — стабильный машиночитаемый код, `message` — пояснение для человека.

| HTTP | `code` | Когда |
|---|---|---|
| 400 | `VALIDATION` | Некорректный запрос |
| 401 | `UNAUTHORIZED` | Нет ключа, ключ неверный или выключен |
| 403 | `FORBIDDEN` | Адрес или Host не разрешён; нет доступа к flow; отмена запрещена |
| 404 | `NOT_FOUND` | Путь, flow или запуск не найден |
| 405 | `VALIDATION` | Неподдерживаемый метод для существующего пути |
| 409 | `CONFLICT` | Flow уже выполняется; запуск уже завершён |
| 429 | `TOO_MANY_REQUESTS` | Адрес заблокирован (есть `Retry-After`) или не истекла пауза между запусками |
| 500 | `INTERNAL` | Внутренняя ошибка |

Ответы на запуск flow в режиме sync — это объект запуска, а не объект ошибки. Их коды описаны в разделе [Эндпоинты](endpoints.md#режим-sync).
