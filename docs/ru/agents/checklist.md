# Чек-лист изменения

## Код

- [ ] Операция пользователя оформлена как `Request` и доступна и в UI, и в CLI.
- [ ] Типы в `src/lib/types.ts` соответствуют Rust.
- [ ] Строки UI есть в `ru.ts` и `en.ts`.
- [ ] Действия ОС идут через `Platform`.
- [ ] Новые ошибки используют подходящий `ErrorCode`.
- [ ] Комментарии — на английском и объясняют только неочевидное.

## Тесты

- [ ] Unit-тесты для новой логики.
- [ ] Интеграционный тест HTTP, если затронут API.
- [ ] Тест компонента, если затронут UI.
- [ ] `pnpm test:all` проходит.
- [ ] `pnpm lint` проходит.

## Документация

- [ ] Изменения внесены в обе версии документации: `docs/en/` и `docs/ru/`.
- [ ] Руководство пользователя (`docs/<язык>/user/`) отражает новое поведение.
- [ ] `docs/<язык>/api/` обновлён при изменении HTTP API.
- [ ] `docs/<язык>/user/cli.md` обновлён при изменении CLI.
- [ ] `docs/<язык>/architecture/` обновлён при изменении устройства.
- [ ] Новые страницы добавлены в индексы.
- [ ] В `CHANGELOG.md` есть запись о видимых пользователю изменениях.
- [ ] `AGENTS.md` обновлён, если изменились правила или карта кода.
