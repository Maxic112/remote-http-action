# Безопасность

Приложение выполняет команды на компьютере по сетевому запросу. Поэтому главная цель — не допустить запуска действий без разрешения владельца.

## Меры

| Угроза | Мера |
|---|---|
| Вызов без разрешения | Каждый запуск требует действующий API-ключ с доступом к flow через группу. |
| Утечка базы данных | Хранится только SHA-256 ключа. Секрет показывается один раз. |
| Утечка ключа через URL и журналы | Ключ принимается только в заголовках. Списки и история содержат имя ключа, а не секрет. |
| Перебор ключей | Ключ содержит около 238 бит энтропии. Есть временная блокировка адреса после серии неудачных попыток. |
| Внедрение команд | Запрос не передаёт параметры в действия: flow статичны и задаются только владельцем. |
| Доступ из чужих сетей | Выбор интерфейса, список разрешённых адресов, проверка заголовка `Host`. |
| Подмена адреса через `X-Forwarded-For` | Заголовок учитывается только от доверенных прокси и разбирается справа налево. |
| Подсматривание вывода команд | Вывод возвращается клиенту только для шагов с явно включённым «Возвращать вывод клиенту». |
| Перехват ключей в сети | HTTPS с самоподписанным или собственным сертификатом; отпечаток SHA-256 для закрепления на клиенте. |
| Утечка секретов через журналы | HTTP-журнал содержит имя ключа, CLI-журнал — только запросы (без ответов, где бывают секреты). |
| Подмена обновления | Скачанный файл сверяется с SHA-256 из релиза; без контрольной суммы обновление не устанавливается. Источник по умолчанию — HTTPS GitHub API. |
| Изменение конфигурации по сети | HTTP API не содержит операций изменения конфигурации. |
| Управление от другого пользователя Windows | Named pipe CLI доступен только SYSTEM, администраторам и пользователю, запустившему приложение. Удалённые клиенты pipe отклоняются. |
| Неожиданное выключение | Задержка старта с окном обратного отсчёта и кнопкой отмены на компьютере. |

## Флаг CLI

Переключатель «Разрешить управление через командную строку» — удобство, а не граница безопасности.
Процесс того же пользователя может изменить файлы приложения напрямую.
Поэтому флаг нельзя изменить через сам CLI, а по умолчанию в релизных сборках он выключен.

## Права администратора

Приложение не запрашивает повышение прав при удалённом вызове.
Шаги с признаком «Требует прав администратора» выполняются, только если повышенные права уже есть у процесса.
Запуская приложение от имени администратора, владелец сознательно разрешает такие шаги.

## Рекомендации по развёртыванию

- Ограничьте интерфейс или список разрешённых адресов локальной сетью.
- Для доступа через интернет используйте reverse proxy с HTTPS и добавьте его в доверенные.
- Выдавайте отдельный ключ каждому клиенту и минимальный набор групп.
- Включайте «Возвращать вывод клиенту» только там, где это необходимо.
