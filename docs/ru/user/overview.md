# Обзор и основные понятия

Remote HTTP Action работает в фоне на компьютере с Windows и держит HTTP-сервер.
Когда на сервер приходит авторизованный запрос к адресу flow, приложение выполняет на этом компьютере заранее настроенные действия.

## Сущности

| Сущность | Назначение |
|---|---|
| **API-ключ** | Секрет, который клиент передаёт в каждом запросе. Без действующего ключа сервер отвечает `401`. |
| **Группа доступа** | Связывает API-ключи с набором flow. Ключ может вызвать flow, только если они состоят в общей группе. |
| **Flow** | Именованная последовательность действий с собственным адресом, например `POST /flow/sleep/`. |
| **Действие** | Один шаг flow: выключение, перезагрузка, сон, задержка, команда, скрипт, запуск программы. |
| **Запуск** | Одно выполнение flow с результатом каждого шага. Хранится в истории. |

```
API-ключ ──┐            ┌── Flow ── действие 1, действие 2, …
           ├─ Группа ───┤
API-ключ ──┘            └── Flow ── …
```

Связь ключей и групп — «многие ко многим»: у ключа может быть несколько групп, у группы — несколько ключей.
Связь групп и flow устроена так же.

## Способы управления

- **Окно приложения** — настройка всех сущностей и параметров.
- **Командная строка** — те же операции через `remote-http-action-cli.exe <команда>` (см. [CLI](cli.md)).
- **HTTP API** — только запуск flow и служебные запросы (см. [HTTP API](../api/index.md)). Изменить конфигурацию по сети нельзя.

## Работа в фоне

При запуске открывается окно, а в области уведомлений Windows появляется иконка.
По умолчанию закрытие окна только скрывает его: сервер продолжает работать.
Полностью выйти из приложения можно через меню иконки в трее (**Выход**).
Поведение настраивается в разделе [Настройки](settings.md#приложение).
