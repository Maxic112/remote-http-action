# Установка, обновление и удаление

## Варианты поставки

| Файл | Что это |
|---|---|
| `remote-http-action_<версия>_x64_ru-RU.msi` | Установщик с интерфейсом на русском |
| `remote-http-action_<версия>_x64_en-US.msi` | Установщик с интерфейсом на английском |
| `remote-http-action_<версия>_x64_portable.zip` | Портативная версия без установки |

Установщики на разных языках устанавливают одно и то же приложение. Выберите любой.
Файл `SHA256SUMS.txt` в релизе содержит контрольные суммы для проверки скачанных файлов.

## Требования

- Windows 10 или 11, 64-разрядная.
- WebView2 Runtime. Он входит в Windows 11 и обновлённую Windows 10; если его нет, установщик предложит загрузить.

## Установщик MSI

1. Запустите MSI и следуйте шагам мастера. Для установки нужны права администратора.
2. Приложение устанавливается в `C:\Program Files\Remote HTTP Action\`:
   - `remote-http-action.exe` — приложение;
   - `remote-http-action-cli.exe` — консольный CLI (см. [Командная строка](cli.md)).
3. В меню «Пуск» появляется ярлык **Remote HTTP Action**.

Данные хранятся в `%APPDATA%\remote-http-action\`: база с ключами, flow и настройками, журналы, сертификат HTTPS.

## Портативная версия

1. Распакуйте архив в любую папку, например на флешку или в `D:\Tools\`.
2. Запустите `remote-http-action.exe`.

Рядом с exe лежит файл `portable.flag`. Пока он есть, данные хранятся в папке `data\` рядом с exe, а не в профиле пользователя.
Если удалить `portable.flag`, приложение будет использовать `%APPDATA%\remote-http-action\`.

Папка с портативной версией должна быть доступна для записи.

## Обновление

Проще всего обновляться из самой программы: раздел **Обновление** (см. [Обновление](update.md)).
Вручную:

- **MSI:** запустите установщик новой версии. Он заменит файлы программы. Данные в `%APPDATA%` сохраняются.
- **Портативная версия:** закройте приложение (трей → «Выход») и замените оба exe новыми. Папку `data\` и `portable.flag` оставьте.

Перед обновлением закройте приложение, иначе Windows не сможет заменить запущенный exe.
Если настроен [автозапуск](autostart.md), а папка программы изменилась, переустановите автозапуск в настройках.

## Удаление

1. Если автозапуск был настроен, удалите его: **Настройки → Автозапуск → Удалить автозапуск**. Задание планировщика не удаляется вместе с программой.
2. Закройте приложение: трей → «Выход».
3. MSI-версия: «Параметры → Приложения → Установленные приложения → Remote HTTP Action → Удалить».
   Портативная версия: удалите папку.
4. Удаление MSI не затрагивает данные. Чтобы удалить и их, удалите папку `%APPDATA%\remote-http-action\`.

## Установленная и портативная версии одновременно

Обе версии используют одно имя канала CLI и по умолчанию один порт. Одновременно может работать только одна из них.
