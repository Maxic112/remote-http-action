# Права администратора

Некоторые действия требуют прав администратора Windows: например, управление службами или изменение системных параметров.

## Индикатор

В шапке окна постоянно виден индикатор:

- зелёный щит **«Администратор»** — приложение запущено с повышенными правами;
- жёлтый щит **«Без прав администратора»** — обычные права.

Щелчок по жёлтому индикатору перезапускает приложение с правами администратора.
Windows запросит подтверждение (UAC), после чего текущее окно закроется и приложение запустится заново.
Если подтверждение отклонено, приложение продолжит работать с обычными правами.

## Как выполняются шаги

Шаг с признаком «Требует прав администратора» выполняется, **только если всё приложение запущено от имени администратора**.
Иначе шаг завершается ошибкой `ADMIN_REQUIRED`, и действует его правило «при ошибке».

Окно UAC при удалённом вызове никогда не показывается: подтвердить его было бы некому.
Чтобы такие flow работали, приложение должно постоянно работать с повышенными правами.

Выключение, перезагрузка и сон обычно не требуют прав администратора на рабочей станции.
