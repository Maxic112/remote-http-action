# Группы доступа

Группа доступа задаёт, какие flow могут вызывать привязанные к ней API-ключи.

## Свойства группы

| Свойство | Описание |
|---|---|
| Название | Уникальное имя группы. |
| Описание | Произвольный комментарий. |
| Flow | Список flow, доступных группе. |
| API-ключи | Ключи, состоящие в группе. |

Привязку ключей можно менять с любой стороны: в карточке группы или в карточке ключа. Это одна и та же связь.

## Правило доступа

Ключ может вызвать flow, если хотя бы одна группа ключа содержит этот flow.
Дополнительно должны выполняться условия:

- ключ включён;
- flow включён.

Если доступа нет, сервер отвечает `403 Forbidden`.
Если в настройках включено «Отвечать 404 вместо 403», сервер отвечает `404 Not Found` и не раскрывает, что такой flow существует.

## Пример

| Группа | Flow | Ключи |
|---|---|---|
| «Питание» | `shutdown`, `reboot`, `sleep` | «Телефон» |
| «Медиа» | `open-player` | «Телефон», «Пульт» |

Ключу «Пульт» доступен только `open-player`, ключу «Телефон» — все четыре flow.
