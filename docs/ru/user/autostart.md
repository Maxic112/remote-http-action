# Автозапуск

Многие действия требуют прав администратора. Обычный автозапуск через ключ реестра `Run` запустил бы приложение без повышенных прав или с окном UAC при каждом входе.
Поэтому автозапуск настраивается через **Планировщик заданий Windows**.

## Настройка

**Настройки → Автозапуск → Установить автозапуск** или `remote-http-action-cli.exe autostart install`.

Для настройки приложение должно быть запущено **от имени администратора**: Windows разрешает создавать задания с наивысшими правами только администраторам.
Если прав нет, перезапустите приложение с повышением (жёлтый щит в шапке) и повторите.

Создаётся задание `Remote HTTP Action` в корне библиотеки планировщика:

| Параметр задания | Значение |
|---|---|
| Триггер | При входе текущего пользователя в систему |
| Права | Наивысшие (`HighestAvailable`) — без окна UAC |
| Действие | Запуск `remote-http-action.exe --minimized` (сразу в трей) |
| Ограничение времени работы | Нет |
| Работа от батареи | Разрешена |
| Повторный запуск | Не запускать второй экземпляр |

## Состояние

| Состояние | Значение |
|---|---|
| Автозапуск настроен | Задание существует и запускает этот исполняемый файл. |
| Автозапуск не настроен | Задания нет. |
| Задание указывает на другой исполняемый файл | Приложение было перемещено или обновлено в другую папку. Нажмите «Переустановить». |

## Удаление

**Удалить автозапуск** или `remote-http-action-cli.exe autostart remove`.
Если задание создано с правами администратора, для удаления тоже могут понадобиться права администратора.

Задание можно посмотреть и изменить вручную в «Планировщике заданий» (`taskschd.msc`).
