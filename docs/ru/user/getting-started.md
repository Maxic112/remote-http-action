# Первый запуск

Установка, портативная версия, обновление и удаление описаны в разделе [Установка, обновление и удаление](installation.md).
Путь к папке данных показан в **Настройки → О программе**.

## Запуск

1. Запустите приложение. Откроется окно, в трее появится иконка.
   HTTP-сервер стартует автоматически на всех интерфейсах, порт `8765`.
2. Состояние сервера показано в шапке окна. Рядом расположен индикатор прав администратора (см. [Права администратора](administrator-rights.md)).

## Первый flow за пять шагов

1. **Flow → Создать flow.** Задайте название, например «Сон». Путь подставится автоматически (`sleep`).
2. На вкладке **Действия** добавьте действие **Спящий режим** и сохраните flow.
3. **Группы доступа → Создать группу.** Отметьте созданный flow.
4. **API-ключи → Создать ключ.** Отметьте группу. Скопируйте показанный ключ: он отображается **только один раз**.
5. Вызовите flow с другого устройства в сети:

```bash
curl -X POST http://<адрес-компьютера>:8765/flow/sleep/ \
  -H "Authorization: Bearer <ключ>"
```

Результат запуска появится на странице **Запуски**.

## Брандмауэр

Windows может запросить разрешение на входящие подключения при первом запуске сервера.
Разрешите доступ для нужных типов сетей. Иначе запросы с других устройств не дойдут до приложения.
