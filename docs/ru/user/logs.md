# Логи

Приложение ведёт три независимых журнала. Действия пользователя в окне приложения не записываются.

| Категория | Файл | Что записывается |
|---|---|---|
| HTTP-запросы | `http.jsonl` | Время, адрес клиента, метод, путь, код ответа, **имя** API-ключа, длительность, User-Agent. Сам ключ не записывается никогда. |
| Команды CLI | `cli.jsonl` | Команда и её параметры, успех или код ошибки, длительность. Ответы (в том числе выданные ключи) не записываются. |
| Выполнение flow | `flow.jsonl` | Две записи на запуск: `started` и `finished`. Во второй — итоговый статус и по каждому шагу: тип, параметры, признак прав администратора, время начала и конца, код выхода, ошибка, вывод команды (до заданного лимита). |

Файлы лежат в `<папка данных>\logs\`. Каждая строка — отдельный JSON-объект (формат JSON Lines), поле `ts` — время записи в UTC.

## Ротация

Для каждой категории в **Настройки → Логирование** задаются:

| Параметр | По умолчанию | Описание |
|---|---|---|
| Запись включена | да | Выключенная категория не пишется. |
| Размер файла, МБ | 5 | При превышении текущий файл переименовывается в `<категория>.1.jsonl`, прежние сдвигаются (`.1` → `.2` …). |
| Хранить файлов | 5 | Сколько архивных файлов сохранять; более старые удаляются. |

Отдельно задаётся, сколько символов вывода команды сохранять в журнале flow (по умолчанию 4096 на поток). Полный вывод (до 16 КБ) хранится в истории запусков.

## Просмотр

Страница **Логи**:

- вкладки по категориям, новые записи сверху;
- поиск по тексту записи;
- щелчок по строке открывает запись целиком;
- кнопки «Открыть папку» и «Очистить» (удаляет все файлы категории).

Из командной строки:

```bash
remote-http-action-cli.exe logs info
remote-http-action-cli.exe logs tail flow --limit 20
remote-http-action-cli.exe logs tail http --grep 10.0.0.5
remote-http-action-cli.exe logs clear cli
```
