# Выпуск релиза

Релизы собираются и публикуются GitHub Actions по тегу версии. Программа узнаёт о новом релизе через механизм [обновления](../user/update.md).

## Шаги

1. **Версия.** Поднимите номер в трёх файлах, он должен совпадать:
   - `package.json`
   - `src-tauri/Cargo.toml` (и обновите `Cargo.lock` любой командой cargo, например `cargo check`)
   - `src-tauri/tauri.conf.json`

   Проверка: `pwsh -File scripts/check-version.ps1`.
2. **Журнал изменений.** Добавьте в `CHANGELOG.md` раздел `## [X.Y.Z] - ГГГГ-ММ-ДД`. Его текст станет описанием релиза и будет показан пользователям на экране «Обновление».
   Проверка: `pwsh -File scripts/release-notes.ps1 -Version X.Y.Z`.
3. **Коммит** в `main` и пуш. Дождитесь зелёного CI.
4. **Тег** и его пуш:

   ```bash
   git tag vX.Y.Z
   git push origin vX.Y.Z
   ```

Workflow `.github/workflows/release.yml`:
- проверяет совпадение тега и версии и наличие раздела в `CHANGELOG.md`;
- прогоняет линтеры и тесты;
- выполняет `pnpm package`;
- публикует релиз с файлами из `src-tauri/target/release/bundle/release/`.

## Состав релиза

| Файл | Назначение |
|---|---|
| `remote-http-action_X.Y.Z_x64_ru-RU.msi` | Установщик (русский) |
| `remote-http-action_X.Y.Z_x64_en-US.msi` | Установщик (английский) |
| `remote-http-action_X.Y.Z_x64_portable.zip` | Портативная версия |
| `SHA256SUMS.txt` | Контрольные суммы |

**Это контракт с установленными копиями программы.** Обновление находит свой файл по окончанию имени (`_x64_ru-RU.msi`, `_x64_en-US.msi`, `_x64_portable.zip`) и устанавливает его, только если SHA-256 совпадает с `SHA256SUMS.txt` или с контрольной суммой файла на GitHub.
Переименование файлов или отказ от контрольных сумм ломает обновление у пользователей.

## Предварительные версии

Тег с суффиксом (`v1.2.0-beta.1`) публикуется как pre-release. Программа его не предлагает: она читает только последний обычный релиз (`/releases/latest`).

## Неизменяемые параметры

- `upgradeCode` в `src-tauri/tauri.conf.json` — по нему установщик заменяет предыдущую версию.
- `identifier` в `src-tauri/tauri.conf.json` — от него зависит работа в единственном экземпляре.
- `REPOSITORY` в `src-tauri/src/update.rs` — откуда программа берёт обновления.
