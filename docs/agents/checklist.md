# Чек-лист изменения

## Код

- [ ] Операция пользователя оформлена как `Request` и доступна и в UI, и в CLI.
- [ ] Типы в `src/lib/types.ts` соответствуют Rust.
- [ ] Строки UI есть в `ru.ts` и `en.ts`.
- [ ] Действия ОС идут через `Platform`.
- [ ] Новые ошибки используют подходящий `ErrorCode`.

## Тесты

- [ ] Unit-тесты для новой логики.
- [ ] Интеграционный тест HTTP, если затронут API.
- [ ] Тест компонента, если затронут UI.
- [ ] `pnpm test:all` проходит.
- [ ] `pnpm lint` проходит.

## Документация

- [ ] Руководство пользователя (`docs/user/`) отражает новое поведение.
- [ ] `docs/api/` обновлён при изменении HTTP API.
- [ ] `docs/user/cli.md` обновлён при изменении CLI.
- [ ] `docs/architecture/` обновлён при изменении устройства.
- [ ] Новые страницы добавлены в индексы.
- [ ] `AGENTS.md` обновлён, если изменились правила или карта кода.
