# Настройки

Настройки сохраняются кнопкой **Сохранить** внизу страницы. Сетевые параметры применяются без перезапуска приложения.

## HTTP-сервер

| Параметр | По умолчанию | Описание |
|---|---|---|
| HTTP-сервер включён | да | Выключенный сервер не принимает подключения. Кнопки «Запустить» и «Остановить» меняют этот же параметр. |
| Интерфейс | `0.0.0.0` (все) | Адрес, на котором сервер принимает подключения. `127.0.0.1` — только с этого компьютера. |
| Порт | `8765` | TCP-порт сервера. |
| Путь вызова flow | `/flow/` | Префикс адресов flow. |
| Путь списка доступных flow | `/get-allowed/` | См. [API](../api/endpoints.md#список-доступных-flow). |
| Путь статуса | `/status/` | См. [API](../api/endpoints.md#статус). |
| Отвечать на запрос статуса без ключа | да | Без ключа возвращается только `{"status":"ok"}`. Если выключено, статус требует ключ. |
| Отвечать 404 вместо 403 | нет | Скрывает существование flow, недоступных ключу. |

Префиксы не должны пересекаться между собой и с зарезервированным `/runs/`.

## Сетевой доступ

| Параметр | Описание |
|---|---|
| Разрешённые адреса клиентов | IP-адреса или подсети в нотации CIDR, по одному в строке (`192.168.1.0/24`, `10.0.0.5`). Пусто — разрешены все. Запросы с других адресов получают `403`. |
| Разрешённые значения заголовка Host | Например `pc.local` или `*.example.com`. Пусто — любые. Защищает от атак DNS rebinding. |
| Доверенные reverse proxy | Адреса прокси. Только для запросов от них адрес клиента берётся из заголовка `X-Forwarded-For`. Он используется для фильтра адресов, блокировок и истории. |
| Блокировка после неудачных попыток | После заданного числа неверных ключей за период адрес блокируется на заданное время (по умолчанию 10 попыток за 300 сек → 900 сек). Заблокированный адрес получает `429`. |

Текущие блокировки перечислены в разделе **Заблокированные адреса**. Блокировку можно снять вручную.

## Управление через CLI

Переключатель «Разрешить управление через командную строку» включает [CLI](cli.md).
Изменить его можно только в окне приложения, но не через CLI.

## Приложение

| Параметр | По умолчанию | Описание |
|---|---|---|
| Оставлять работать в трее при закрытии окна | да | Если выключено, закрытие окна завершает приложение. |
| Язык | как в системе | Русский или английский. |
| Хранить запусков | 200 | Размер истории запусков. |
