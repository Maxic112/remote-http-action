# Обновление

Новые версии публикуются в [релизах репозитория проекта на GitHub](https://github.com/Maxic112/remote-http-action/releases). Программа сама узнаёт о них и обновляется по нажатию кнопки.

## Проверка

- Раз в сутки программа запрашивает последний релиз. Первая проверка — через минуту после запуска, если с прошлой прошло больше суток.
- Если вышла новая версия, у пункта меню **Обновление** появляется оранжевая точка.
- Кнопка **Проверить сейчас** выполняет проверку немедленно.
- Автоматическую проверку можно выключить в разделе **Обновление → Параметры обновления**.

На экране обновления показаны:
- установленная версия и тип установки (MSI или портативная);
- время последней проверки;
- для новой версии — название, дата выхода и описание изменений.

## Установка обновления

### Версия, установленная из MSI

1. Нажмите **Скачать и установить**. Скачивается установщик на языке интерфейса.
2. Программа закрывается и открывает мастер установки: нажмите «Далее» и «Установить».
3. После установки программа запускается снова, уже в новой версии.

Если закрыть мастер без установки, программа запустится в прежней версии.

### Портативная версия

1. Нажмите **Скачать**. Скачивается и распаковывается архив новой версии.
2. Нажмите **Перезапустить и обновить**. Программа закрывается, оба exe заменяются новыми, программа запускается снова.
   Папка `data\` и файл `portable.flag` не затрагиваются.

Папка с портативной версией должна быть доступна для записи.

### После обновления

Скачанные файлы удаляются сразу после установки. Если обновление прервалось, остатки удаляются при следующем запуске программы.
Временная папка — `%TEMP%\remote-http-action-update`.

Ход последнего обновления записывается в `logs\update.log` в папке данных.

## Безопасность

- Каждый скачанный файл сверяется с контрольной суммой SHA-256 из релиза (`SHA256SUMS.txt` или контрольная сумма файла на GitHub).
  Файл, который не совпал с суммой или опубликован без неё, не устанавливается.
- Установщик MSI запускается с правами программы: если она работает от имени администратора, мастер не запрашивает UAC, иначе Windows покажет запрос.
- Сборка для разработки не обновляется.

## Источник обновлений

По умолчанию — релизы проекта на GitHub. Поле **Источник обновлений** позволяет указать другой адрес, например внутренний сервер-зеркало.
Он должен отвечать в формате GitHub API `GET /repos/<владелец>/<репозиторий>/releases/latest`:
- поле `tag_name` — версия, например `v1.2.0`;
- `body` — описание изменений;
- `assets` — файлы с полями `name`, `browser_download_url`, `size`.

Файлы релиза определяются по окончанию имени: `_x64_ru-RU.msi`, `_x64_en-US.msi`, `_x64_portable.zip`.

Пустое поле возвращает источник по умолчанию.

## Командная строка

```bash
remote-http-action-cli.exe update status
remote-http-action-cli.exe update check
remote-http-action-cli.exe update download
remote-http-action-cli.exe update install
```
