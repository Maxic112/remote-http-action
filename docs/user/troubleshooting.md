# Решение проблем

## Сервер не запускается

В шапке окна показано «Ошибка сервера». Причина видна в **Настройки → HTTP-сервер**.

| Сообщение | Что сделать |
|---|---|
| `cannot listen on 0.0.0.0:8765: … (os error 10048)` | Порт занят другой программой или вторым экземпляром приложения. Выберите другой порт или закройте программу, которая его занимает (`netstat -ano \| findstr :8765` покажет PID). |
| `cannot listen on …: (os error 10049)` | Выбранный адрес интерфейса больше не принадлежит компьютеру, например сменился IP. Выберите «Все интерфейсы» или актуальный адрес. |
| `cannot load TLS certificate …` | Файлы своего сертификата не найдены или не в формате PEM, либо ключ не соответствует сертификату. Проверьте пути или переключитесь на самоподписанный сертификат. |

## Запросы с других устройств не доходят

1. Проверьте с самого компьютера: `curl http://127.0.0.1:8765/status/`. Если не отвечает — см. «Сервер не запускается».
2. **Брандмауэр Windows.** Разрешите входящие подключения для `remote-http-action.exe`. В «Брандмауэр Защитника Windows → Разрешение взаимодействия с приложением» должна стоять отметка для нужного типа сети.
   Если сеть определена как «Общедоступная», а разрешение дано только для «Частной», подключения блокируются.
3. **Интерфейс.** Если в настройках выбран `127.0.0.1`, сервер доступен только с этого компьютера.
4. **Разрешённые адреса и Host.** Ответ `403` с текстом `client address is not allowed` или `host is not allowed` означает, что запрос отсечён фильтрами в **Настройки → Сетевой доступ**.
5. **Блокировка.** Ответ `429` — адрес заблокирован после неудачных попыток авторизации. Снимите блокировку в настройках или дождитесь её окончания.

## Ответ 401

- Ключ передаётся не в заголовке `Authorization: Bearer …` или `X-API-Key`.
- Ключ выключен или перевыпущен. Ключ показывается один раз: если он утерян, перевыпустите его.

## Ответ 403 или 404 при вызове flow

- `403` — ключ не входит ни в одну группу, где есть этот flow (см. [Группы доступа](access-groups.md)).
- `404` — flow не существует, выключен, или включено «Отвечать 404 вместо 403».
- Проверьте префикс: по умолчанию адрес `POST /flow/<путь>/`, но префикс можно изменить в настройках.

## Шаг завершается ошибкой `ADMIN_REQUIRED`

Шаг помечен «Требует прав администратора», а приложение запущено без них.
Перезапустите приложение с повышением (жёлтый щит в шапке) или настройте [автозапуск](autostart.md), который запускает его с правами администратора.

## Запуск приложения сразу завершается, хотя программа ещё открыта

Программа — лаунчер: она передала работу другому процессу и вышла. Выберите режим ожидания «Пока работают процесс и все его дочерние» или «Пока есть процессы с указанным именем» (см. [Действия](actions.md#режимы-ожидания)).

## HTTPS: клиент не доверяет сертификату

Самоподписанный сертификат не подписан доверенным центром. Сверьте отпечаток из настроек и закрепите его на клиенте, либо добавьте `cert.pem` в доверенные (см. [HTTPS](https.md)).

## CLI

| Сообщение | Что сделать |
|---|---|
| `remote-http-action is not running` (код 3) | Запустите приложение. CLI управляет только работающим экземпляром. |
| `CLI access is disabled` (код 4) | Включите **Настройки → Управление через CLI** в окне приложения. |
| Вывод появляется после приглашения терминала, код выхода не виден | Используйте `remote-http-action-cli.exe`, а не `remote-http-action.exe`. |
| `access to the running instance was denied` | Команда запущена от другого пользователя Windows. CLI принимает команды только от пользователя, запустившего приложение, и от администраторов. |

## Автозапуск не срабатывает

- В **Настройки → Автозапуск** состояние «Задание указывает на другой исполняемый файл» — программа была перемещена. Нажмите «Переустановить».
- Откройте `taskschd.msc`, найдите задание **Remote HTTP Action** и посмотрите вкладку «Журнал» или «Результат последнего запуска».

## Где искать подробности

- Страница **Запуски** — результат и вывод каждого шага.
- Страница **Логи** — HTTP-запросы с кодами ответа, команды CLI, полный ход выполнения flow (см. [Логи](logs.md)).
