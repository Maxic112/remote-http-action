# Запуски и отмена

Каждое выполнение flow сохраняется как **запуск**.

## Статусы

| Статус | Значение |
|---|---|
| `pending` | Принят и ожидает (например, в очереди). |
| `delayed` | Идёт обратный отсчёт задержки старта. |
| `running` | Выполняются шаги. |
| `success` | Все шаги выполнены успешно. |
| `failed` | Хотя бы один шаг завершился ошибкой. |
| `canceled` | Запуск отменён. |
| `timeout` | Превышен таймаут flow. |

## История

Страница **Запуски** показывает последние запуски с источником (HTTP, CLI, окно), именем API-ключа и адресом клиента.
Щелчок по строке открывает подробности: результат, код выхода и вывод каждого шага.
Количество хранимых запусков задаётся в настройках (по умолчанию 200).

Запуски, прерванные закрытием приложения, при следующем старте помечаются как `failed`.

## Запуск из окна

Кнопка ▶ в списке flow запускает flow немедленно, без API-ключа. Так удобно проверять настройки.

## Задержка старта и отмена

Если у flow задана задержка старта, на компьютере открывается окно с обратным отсчётом и кнопкой **Отменить запуск**.
Человек за компьютером может отменить выключение или перезагрузку, запрошенные удалённо.

Отменить активный запуск можно:

- кнопкой в окне обратного отсчёта или на странице **Запуски** (работает всегда);
- HTTP-запросом `POST /runs/{id}/cancel` тем же ключом, которым запуск создан, если у flow включено «Можно отменить»;
- командой `remote-http-action-cli.exe runs cancel <id>`, если у flow включено «Можно отменить».

При отмене выполняющейся команды её процесс завершается.
