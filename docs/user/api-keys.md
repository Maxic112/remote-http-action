# API-ключи

API-ключ — секрет, которым клиент подтверждает право вызывать flow. Без действующего ключа сервер отвечает `401 Unauthorized`.

## Свойства ключа

| Свойство | Описание |
|---|---|
| Название | Понятное имя: «Телефон», «Умный дом». Отображается в истории запусков. |
| Ключ | Строка вида `rha_` + 40 символов. В списке видны только первые символы (`rha_AbCdEfGh…`). |
| Группы доступа | Одна или несколько групп; определяют, какие flow доступны ключу. |
| Включён | Выключенный ключ отклоняется так же, как неверный. |
| Последнее использование | Время последнего успешного запроса с этим ключом. |

## Хранение

Приложение хранит только хеш ключа (SHA-256). Сам ключ показывается **один раз** — сразу после создания или перевыпуска.
Восстановить потерянный ключ невозможно, его можно только перевыпустить.

## Операции

- **Создать** — задайте название и группы; скопируйте ключ из открывшегося окна.
- **Изменить** — название и группы.
- **Включить / выключить** — переключатель в списке.
- **Перевыпустить** — выдаёт новый ключ. Старый перестаёт работать сразу.
- **Удалить** — ключ удаляется вместе с привязками к группам.

## Передача ключа в запросе

```
Authorization: Bearer rha_...
```

или

```
X-API-Key: rha_...
```

Ключ в строке запроса (`?key=...`) не принимается: такие адреса часто попадают в журналы прокси и историю браузера.
