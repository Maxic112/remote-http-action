# Эндпоинты

| Метод | Путь | Ключ | Назначение |
|---|---|---|---|
| `POST` | `/flow/{path}/` | да | Запуск flow |
| `GET` | `/runs/{run_id}` | да | Статус запуска |
| `POST` | `/runs/{run_id}/cancel` | да | Отмена запуска |
| `GET` | `/get-allowed/` | да | Список flow, доступных ключу |
| `GET` | `/status/` | нет* | Статус приложения |

\* Без ключа — минимальный ответ, если включён публичный статус.

Запрос к существующему пути с другим методом получает `405`.

## Запуск flow

```
POST /flow/{path}/
```

Тело запроса не требуется.

### Режим sync

Сервер ждёт окончания flow: задержка старта + таймаут flow + 5 секунд. Затем возвращает результат:

```json
{
  "run_id": "4f1c…",
  "flow": "restart-spooler",
  "status": "success",
  "created_at": "2026-01-01T10:00:00.000Z",
  "started_at": "2026-01-01T10:00:00.010Z",
  "finished_at": "2026-01-01T10:00:01.200Z",
  "error": null,
  "steps": [
    {
      "index": 0,
      "type": "cli_command",
      "status": "success",
      "started_at": "…",
      "finished_at": "…",
      "exit_code": 0,
      "stdout": "…",
      "stderr": ""
    }
  ]
}
```

Поля `stdout` и `stderr` присутствуют только у шагов с включённым «Возвращать вывод клиенту».

| Статус запуска | HTTP-код |
|---|---|
| `success` | `200` |
| `failed` | `500` |
| `timeout` | `504` |
| `canceled` | `409` |
| не завершился за время ожидания | `202` (как в режиме async) |

### Режим async

```
HTTP/1.1 202 Accepted

{ "run_id": "4f1c…", "status": "pending", "status_url": "/runs/4f1c…" }
```

### Ошибки запуска

| Код | Причина |
|---|---|
| `404` | flow не существует или выключен |
| `403` | ключ не имеет доступа к flow |
| `409` | flow уже выполняется (политика «Отклонять») |
| `429` | не истекла пауза между запусками |

## Статус запуска

```
GET /runs/{run_id}
```

Возвращает объект запуска в том же формате, что и sync-ответ.
Запуск доступен только ключу, которым он был создан. Для других ключей ответ — `404`.

## Отмена запуска

```
POST /runs/{run_id}/cancel
```

```json
{ "run_id": "4f1c…", "status": "canceling" }
```

| Код | Причина |
|---|---|
| `403` | у flow выключено «Можно отменить» |
| `404` | запуск не найден или создан другим ключом |
| `409` | запуск уже завершён |

## Список доступных flow

```
GET /get-allowed/
```

Возвращает включённые flow, доступные ключу. Используется клиентскими приложениями для построения интерфейса.

```json
{
  "key": "Телефон",
  "flows": [
    {
      "path": "sleep",
      "url": "/flow/sleep/",
      "method": "POST",
      "name": "Сон",
      "description": "",
      "response_mode": "sync",
      "start_delay_sec": 0,
      "cancelable": true,
      "client_meta": { "icon": "moon", "color": null, "category": "Питание", "tags": [], "confirm_on_client": false }
    }
  ]
}
```

## Статус

```
GET /status/
```

Без ключа (если публичный статус включён):

```json
{ "status": "ok" }
```

С действующим ключом:

```json
{ "status": "ok", "version": "0.1.0", "uptime_sec": 3600, "elevated": true }
```

`elevated` показывает, запущено ли приложение с правами администратора.
