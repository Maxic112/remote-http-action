# HTTP API

HTTP API предназначен для запуска flow и служебных запросов. Изменить конфигурацию по сети нельзя.

- [Авторизация](authentication.md) — передача API-ключа, сетевые ограничения, блокировки.
- [Эндпоинты](endpoints.md) — запуск flow, статус запуска, отмена, список доступных flow, статус приложения.
- [Ошибки и коды ответа](errors.md) — формат ошибок и HTTP-статусы.

Базовый адрес — `http://<адрес>:<порт>`, по умолчанию порт `8765`.
Пути `/flow/`, `/get-allowed/` и `/status/` настраиваются (см. [Настройки](../user/settings.md#http-сервер)).
В примерах используются значения по умолчанию.
Завершающая косая черта в путях необязательна.
